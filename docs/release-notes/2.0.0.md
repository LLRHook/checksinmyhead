# Billington 2.0.0

Billington 2.0.0 begins the collaborative trip experience.

- Receipt entry supports explicit multi-currency selection with USD as the default.
- AI receipt parsing can return currency metadata for review, including currencies such as PEN, EUR, GBP, and CAD.
- Bills send original and display currency metadata to the backend for auditable conversion work.
- Tabs remain account-less and app-first, preserving the existing anonymous member model.
- The app and iOS marketing version are now 2.0.0.

The collaborative tab dashboard, server-side exchange-rate caching, app deep links, and tab-scoped payment profiles continue in the next implementation stages.
