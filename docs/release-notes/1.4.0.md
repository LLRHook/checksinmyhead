Billington 1.4.0 introduces a simpler way to split receipt-based bills with friends.

• Lazy Mode is now a visible option from the main screen. The bill creator can select their own items in the app before sharing, so friends only see the items that still need to be claimed.
• Friends get a receipt-style web view where they can select items, split shared items, and see tax and tip included transparently in their total.
• Each person has a focused payment screen with Venmo support, other payment details, and a Mark as Paid action.
• Collaborative updates are safer when multiple people are using the same bill at once.
• Refreshed bill summaries reduce repetition and make the remaining balance easier to understand.
