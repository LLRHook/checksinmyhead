# Billington 2.0.7

- Lazy Mode now saves a selection in one update when you tap Review, keeping item taps responsive while protecting simultaneous edits.
- Open Lazy Mode bill pages refresh when you return to them and show which receipt items have been paid.
- Paid shares stay locked, and the app no longer shows a stale Review total after payment.
- The tab display currency chooser is now a scrollable bottom sheet.
